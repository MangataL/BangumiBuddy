# 字幕子集化与替换

## Sub-features

带点的视频名、语言和 forced 标记；磁力任务多份字幕缺字体汇总；忽略失败后转移原件；初始化后重新转移；替换已经存在的同名错误字体。样例覆盖中文样式、日文行内字体名，以及同一家族的常规体和粗斜体。

## How to get to it (user POV)

在设置中开启字幕子集化、生成新文件及覆盖已有内嵌字体。在磁力管理中打开已下载任务，点击「转移文件」。验证对象是用户从媒体库播放时加载的 `.subset.zh-CN.forced.ass`。

## Driving it with verify.py

从仓库根目录运行 `python .agents/skills/verify/scripts/verify.py subtitles "$proof"`。它使用一段真实视频、两条字幕轨和带同名错误轮廓的旧字体。

1. 无字体索引时执行严格转移。任务显示缺字体及其来源，媒体库无文件。打开忽略后重试，任务转移成功，详情带警告，原字幕字节完整。
2. 通过正式 API 初始化字体库，再以严格模式重试。任务详情应指向真正入库的视频，媒体库与下载目录的子集字幕应是同一硬链接。保留完整视频基础名和轨道后缀。
3. 从最终字幕解码每个附件，按内部名字和使用码点核对字体。保存 0.5、1.5、2.5 秒的成对画面。分别验证中文台词「春日山川」、日文字体名控制的「AAA」、同一字体家族的粗斜体「AAA」。
4. 每个时刻看四张图。参考图强制使用指定的完整字型；实际图只允许内嵌字体和固定回退字体；去附件图显示回退字形；旧字幕图显示错误轮廓。在 `render.json` 检查实际对参考的差异为 0，两个负对照的差异均达到门槛。客户端未报错、存在附件或日志选中同一个名字，都不足以单独验收。

另外保留一条原本没有附件的字幕轨。它应生成可播放的子集副本，在同一句中文台词上与完整字体参考图逐像素一致。

以下路径按具体变更追加验收，分别记录实际运行结果。

| 变更涉及 | 操作与判据 |
| --- | --- |
| 覆盖已有内嵌字体开关 | 用同一份已有有效附件的字幕分别关闭、开启覆盖。关闭时核对原字幕哈希与实际画面，开启时使用同名错轮廓的源字幕验证替换。 |
| 覆盖原文件或生成新文件 | 在独立下载目录分别运行。按设置核对源文件哈希、入库副本和语言后缀，再渲染播放器实际打开的轨道。 |
| 种子随附字体、TTC/OTF 或 SSA | 将真实故障文件放进对应来源，固定所需的 face、台词和时间。保留完整 face 参考、入库帧与回退帧。 |
| 具体播放器报告异常 | 用该播放器和版本在独立配置中打开入库视频，明确选中目标字幕轨，留存同一时间点的截图和字体选择日志（客户端支持时）。 |

## Gotchas

原字幕和旧附件故意保留同样的名称，按附件文件名比较会漏报。回放真实故障时，保留原来的 ASS 样式、行内覆盖、语言名、字重和出错台词。若涉及 SSA、字体集合、软链接、覆盖原字幕或特定播放器，在同一条真实入口增加对应样例；固定样例的结果只覆盖所运行的组合。
