# RSS 订阅与手动选季

## Sub-features

按最早有效发布日期推荐季度、更改季度后更新集数、分别保存同名剧集的两个季度。手动 RSS 和发现页字幕组都通往订阅确认框。

## How to get to it (user POV)

从 `/` 选择「添加订阅」，或从 `/discover` 选择番剧和字幕组进入确认。回到订阅管理，按季打开对应海报。

## Driving it with verify.py

运行 `serve` 后从 `doctor` 的 `fixtures` 取得本次样例服务 URL。手动 RSS 入口分别输入此 URL 加 `/rss/1` 和 `/rss/2`。这两条供稿分别在 2020 和 2022 年发布。确认框应选中第 1 季（12 集）和第 2 季（10 集）。在确认前切换季号，观察总集数联动，再选回各自的季并订阅。刷新订阅管理，保存两张卡片与各自详情截图。用以下命令复核持久化结果。

```sh
python "$driver" api "$session" GET /bangumis/base
```

## Gotchas

这两条样例测日期、集数与分组。样例未提供季海报图片或蜜柑发现页目录。涉及封面时需提供两张能区分的季海报，核对预览与最终卡片；涉及发现入口时需准备可供选择的番剧、字幕组与 RSS。单独验证手动 RSS 后，将缺少数据的其他旅程记为未验证。
