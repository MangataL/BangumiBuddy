# BangumiBuddy 功能验收地图

从项目根目录依照 [启动说明](../SKILL.md) 建立实例。证据目录属于本次运行。功能涉及多个入口时，每个受影响的入口都要留有结果。

| 用户功能 | 入口 | 验收重点 |
| --- | --- | --- |
| [字幕子集化与替换](subtitles.md) | 磁力管理 → 转移文件 | 入库字幕的字形、样式与像素，严格和忽略模式 |
| [磁力任务与转移](magnets.md) | 磁力管理 → 添加磁力任务 → 任务详情 | 用户选择的文件、媒体库路径、重试状态 |
| [字体库](fonts.md) | 设置中心 → 工具设置 → 初始化 | 建库结果与实际字幕使用的字体 |
| [订阅与选季](subscriptions.md) | 订阅管理添加 RSS；发现页选择字幕组 | 两季独立、手动选季、刷新后持久化 |

字幕自动旅程覆盖前三项的 API 与文件侧效果。需要验证界面或第三方客户端兼容性时，另外操作对应客户端。样例未提供某条旅程的前置数据时，在结论里注明哪一步缺少什么数据；不能用相邻入口代替。
